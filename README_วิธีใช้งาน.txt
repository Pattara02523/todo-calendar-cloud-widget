===================================================================
คู่มือการใช้งาน: โปรแกรม To-Do List & ตารางงาน Google Calendar 1 สัปดาห์
===================================================================

ภายในชุดโปรแกรมนี้ประกอบด้วย:
1. desktop_todo_calendar_widget.html
   - โปรแกรมหลัก (แสดง To-Do List + ตารางงาน Google Calendar 1 สัปดาห์จากบัญชีของคุณ)
   - รองรับการเพิ่ม/ลบ/เช็กงาน บันทึกข้อมูลอัตโนมัติในเครื่อง และเชื่อม Google Calendar สด

2. Open_Widget_Right_Corner.bat
   - ดับเบิลคลิกเพื่อเปิดโปรแกรมในโหมดหน้าต่างกะทัดรัดชิดมุมขวาของหน้าจอทันที
   - หน้าต่างจะแสดงผลค้างไว้ตลอดเวลาจนกว่าคุณจะปิดหน้าต่างหรือปิดคอมพิวเตอร์

3. Install_Desktop_And_Startup.bat
   - ดับเบิลคลิกเพียงครั้งเดียวเพื่อสร้างไอคอนไว้บนหน้าจอ Desktop ของคุณ
   - พร้อมลงทะเบียนใน Windows Startup เพื่อให้เปิดขึ้นมาอยู่มุมขวาจออัตโนมัติทุกครั้งที่เปิดคอม

4. desktop_widget_always_on_top.py
   - สำหรับผู้ที่ติดตั้ง Python ในเครื่อง: รันไฟล์นี้เพื่อเปิดหน้าต่าง Native Widget ที่ล็อกโหมด Always on Top (ลอยทับบนสุดเสมอ) ที่มุมขวาบนของจอ
